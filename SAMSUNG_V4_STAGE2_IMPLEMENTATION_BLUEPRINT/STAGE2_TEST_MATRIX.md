Stage 2 НЕ запускались; таблица — обязательные требования к будущей

  операторская процедура.

  при любом красном пункте.

## 7. Критерии приёмки этапа (общие)

Этап считается принятым, когда:
1. все пункты матрицы, назначенные этапу (колонка «Этап»), зелёные;
2. полный pytest зелёный (789 существующих + новые);
3. golden-пункты соответствующего этапа дают нулевой diff торговой логики;
4. SHA256 всех изменённых файлов зафиксирован (SHA256SUMS_stage2-<буква>.txt);
5. решение владельца, назначенное этапу в roadmap, зафиксировано письменно.

Любой красный пункт = этап не принят -> исправление в рамках того же
этапа (не «поверх» следующим этапом) -> повторный полный прогон.
