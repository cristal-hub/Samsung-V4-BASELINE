## 2. Требование §4 ТЗ — расчёт проскальзывания (LONG)

**Формулировка ТЗ:** total_exit_slippage_ps = exit_decision_price -
exit_exec_price; attempt_slippage_ps = attempt_snapshot_price -
attempt_exit_exec_price (по исполнениям своей попытки; без исполнений —
NOT_APPLICABLE); exit_exec_price — средневзвешенная по всем
подтверждённым исполнениям; сохранение ранее согласованного разделения
(total/attempt/stop-поля/exit_exec_price) без смешивания и без двойного
учёта в REALIZED LOSS.

| Требование ТЗ | Исполнение Stage 2.3.3 | Документы / разделы | Тесты |
